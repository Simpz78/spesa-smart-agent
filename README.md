# Spesa Smart Agent 🛒

Agente intelligente per il monitoraggio settimanale delle offerte e promozioni da volantini PDF sui supermercati di riferimento (Bologna & Casalecchio di Reno).

## Negozi Monitorati
- **Esselunga** - Casalecchio di Reno (Piazza degli Etruschi)
- **Coop Alleanza 3.0** - Bologna (Via Casciarolo)
- **Ipercoop** - Bologna (Centro Commerciale Meraville)
- **Eurospar** - Bologna (Via Stalingrado)
- **Interspar** - Bologna (Via Larga)
- **Lidl** - Bologna (Via Stalingrado)

## Funzionalità
- 📥 **Download automatico** dei volantini PDF settimanali.
- 🎯 **Filtro su paniere personalizzato**: monitora solo i prodotti consumati regolarmente.
- 🚨 **Alert Scorte**: segnalazioni speciali per sconti $\ge 25-30\%$, 2x1 o multipack maxi.
- ⏰ **Automazione settimanale** (es. ogni giovedì mattina).
